# Виктор Скважина — версия 0.2

- `Viktor-Skvazhina-0.2.apk` — установка на Android 8.0 и новее.
- `Viktor-Skvazhina-0.2-full-project.zip` — полный проект, ресурсы, тесты и APK.

Откройте файл и нажмите Download raw file (значок загрузки).
Новые реплики ведущего и дополнительные вопросы пока текстовые.
APK подписан отладочным ключом; обновление установленной сборки с другим ключом подписи не поддерживается. Сначала сохраните нужные данные установленного приложения.
