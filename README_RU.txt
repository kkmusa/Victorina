SechinQuiz — тестовый прототип

Открой папку SechinQuiz в Android Studio через File > Open.
При первом запуске Gradle скачает необходимые зависимости. Нужен интернет.

Что уже работает:
- стартовое меню;
- случайный выбор 3 вопросов;
- случайное перемешивание ответов;
- озвучка номера вопроса, вопроса, вариантов А/Б/В/Г и ответов;
- проверка ответа и экран результата.

Важно: в исходном Word у вопроса №20 не было звёздочки у правильного варианта. Поэтому вопрос №20 сохранён в базе и аудио, но временно исключён из случайной игры.
